这一版把常用的东西搬到了贴纸上：底栏能搜会话，也能随时看配额用量。

## 新功能

- 点贴纸底栏的放大镜，按会话标题或仓库名筛选，在「已归档」里搜归档的会话
- 底栏显示 5 小时、7 天和各模型 7 天的配额用量，越满越红

## 改进

- 设置、固定、搜索、用量收进底部一条栏，顶部只放状态页签
- 吸边后的细条和吸附动画更好看
- 卡片按钮、打开终端、改名和写便签更顺手
- 内置字体，Windows 和 macOS 上显示一致
- 窗口不能缩得太小，页签不再被挤压

## 修复

- 设置页「更新」按钮鼠标停上时不再变灰

## 注意

- 有新版本时不再弹横条，改为齿轮按钮上的红点，在设置的「关于」里安装
