这一版把桌面贴纸换成了灵动岛。它常驻屏幕顶部，谁在跑、谁在等你一眼就能看到，有事时弹出提醒。

## 灵动岛

- 收起时显示额度、会话头像和一双跟着状态变神态的眼睛
- 点一下展开，看要紧的会话和各家额度，点头像打开会话
- 会话需要你时弹出提醒，鼠标停在上面不会消失
- 可以拖到屏幕顶部任意位置，也可以收成一道细条
- 全屏程序在前台时自动藏起来
- 有刘海的 Mac 上岛包住刘海，没有刘海时从菜单栏图标弹出

## 改进

- Kimi 的提问可以在对话页点选作答
- 工具调用显示成中文动作，不再是原始工具名
- 手机页能导出对话、分叉会话，能添加到主屏幕
- 设置里可以导出诊断日志，反馈问题时附上

## 注意

- 贴纸和会话列表窗口去掉了，会话都在对话窗口的侧栏里
- 单击托盘图标打开对话窗口，托盘菜单去掉了「找回贴纸」「打开会话列表」

## 修复

- 新建会话带的第一句话不再卡住或被补发一遍
- 往上翻历史时提问卡不再被撤掉，收起后也不再弹回来
- iOS Safari 上输入框能正常显示
