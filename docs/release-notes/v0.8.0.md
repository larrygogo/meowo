这一版把桌面贴纸换成了灵动岛，Windows 和 macOS 都是。岛常驻屏幕顶部，谁在跑、谁在等你一眼可见，点一下展开会话和额度，有事时弹出提醒。会话列表统一看对话窗口的侧栏。另外修了几处提问卡和新建会话会卡住的地方，kimi 的提问在对话页也能直接点选作答了。

## 灵动岛（Windows）

- 贴纸和贴边缩略条换成屏幕顶部的灵动岛，可以左右拖动换位置
- 收起时显示额度环、一双会随状态变神态的眼睛、时间，以及每个会话一个头像。在跑的会话外圈是绿色的弧，跑完等你的亮一个黄点，颜色和对话窗侧栏一致
- 点一下展开面板，看最要紧的会话和各家额度；点头像直接打开那个会话；点岛外面才收起
- 面板标题栏可以新建会话、打开对话窗口、打开设置；没有会话时中间的按钮打开对话窗口
- 用量页每家一个叠环，一档额度一圈，数值和名称列在环下面；额度显示已用多少
- 会话需要你时弹出提醒，几条一起来会排队，鼠标停在提醒上就不会消失
- 极简模式：收起时只在屏幕顶边留一道细条，鼠标移上去变回胶囊。在面板上或设置里开关
- 全屏程序在前台时岛会藏起来
- 单击托盘图标打开对话窗口，托盘菜单去掉了「找回贴纸」「打开会话列表」

## 灵动岛（macOS）

- 有刘海的 MacBook：岛包住刘海，额度和眼睛在刘海左边，会话头像在右边。点开的面板和提醒从刘海下面开始画
- 没刘海时（外接屏、合盖、老机型）：屏幕上不画岛，点菜单栏图标在下方弹出面板，样子和系统菜单栏的弹出面板一致
- 菜单栏图标换成一双会动的眼睛：空闲时眨眼，在跑时眼珠左右转并变绿，要你处理时睁大变橙，出错时变红。图标右边显示最要紧的那个会话的标题和状态，没会话时显示额度
- 插拔外接屏、合盖开盖后几秒内自动换到对应的显示方式

## 对话窗

- kimi 的提问（AskUserQuestion）在对话页弹出提问卡：单选、多选、确认提交都能直接点。需要自己写答案的「Other」仍在终端里填
- 新建会话时带的第一句话，终端一就绪就发出去。此前有的 CLI 要等你在终端手动发一句才认领会话，第一句话会卡住，之后又被补发一遍
- 往上翻历史不再把挂着的提问卡撤掉
- 提问卡点「仅收起」后不再隔两秒又弹回来；终端页里提问卡默认收成一条，不再盖住终端里的真表单
- 对话顶栏的标题和侧栏一致，第一回合还没跑完时也一样
- forked skill（如 `/code-review <PR 链接>`）派出的子任务展开后能看到内容，参数长也不再是空的
- 时间线上常用工具和 MCP 工具显示中文动作词，不再是 `TaskStop`、`mcp__xxx__click` 这类原名

## 手机页

- 能导出对话（手机浏览器直接下载 .md），能添加到主屏幕当 App 用
- 能分叉会话，输入框打 `@` 能引用文件
- iOS 27.3 的 Safari 上输入框不再看不见
- 请求超时的提示改成「连不上桌面端，请求超时」，不再说「正在重试」

## 其它

- 安装版把诊断输出写进 `~/.meowo/logs/meowo.log`，设置里能导出，反馈问题时附上
- 官网的 Windows 介绍改成灵动岛
