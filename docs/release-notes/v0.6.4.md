这一版集中打磨交互：Kimi 会话不再被误报「待交互」，审批卡会警示危险命令，设置能搜索了，子任务在进度面板里逐条显示。

## 状态与提醒

- Kimi 正在干活时不再被误报成「待交互」
- 同一次等待不再反复弹通知。审批通知会一直留着，点「打开会话」就能过去

## 对话窗

- 进度面板里的子任务逐条显示，各自有状态和耗时
- 多问题的提问表单可以在卡片里作答
- 审批卡对 `rm -rf`、`sudo` 这类危险命令标红，长命令能展开和复制
- 斜杠命令支持模糊匹配和参数提示，输入 @ 能补全文件
- 对话内容更新更及时，命令输出里不再出现乱码

## 终端

- Ctrl+点击文件路径会在文件管理器里打开，右键菜单能复制、粘贴、全选、搜索
- 对话窗和外部终端连着同一个会话时，界面不再反复重排
- 启动失败时显示原因，卡住时横幅上可以「结束并恢复」
- 回滚行数可以在设置里调

## 看板与设置

- 新建会话时显示「正在启动」占位卡
- 选择跳过权限确认的启动方式时，会标红并说明风险
- 设置能搜索了，外观分区能实时预览贴纸
- 引导新增两步，说明会往 CLI 配置写入 hooks、写前备份、怎么移除
- 安装 CLI 和下载更新都能取消

## 窗口与托盘

- Windows 托盘图标单击开合贴纸，双击打开对话窗
- 设置里能开启点击穿透，贴纸不挡鼠标，按住 Alt 临时恢复
- 双屏时贴纸不再误吸到中间的边，拖到屏边会显示落点
- 键盘和读屏软件操作更顺
