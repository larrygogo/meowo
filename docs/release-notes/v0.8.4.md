这一版让对话窗在五家 Provider 上表现一致，Lead 也能用在 Codex、Kimi、Gemini、OpenCode 上。手机上可以切换账号、查看用量。

## 对话窗五家统一

- 同一个状态在侧栏、灵动岛、通知和手机页里只用一个词
- 五家的提问卡和审批卡统一成一种，桌面和手机都能作答
- 工具调用按读、写、命令、搜索等分类显示，失败标红
- Codex 和 Gemini 的改动也显示改了哪些行和增删行数
- 暂时做不到的操作会排队或置灰，并写明原因
- Codex 可以在对话窗里切思考档

## 运行状态

- 只剩后台任务在跑时，会话不再显示「工作中」
- 一直没有结果的调用，回合结束后显示「已中断」
- 不再误报「未确认送达」，这类消息改为「放回输入框」

## Lead

- Codex、Kimi、Gemini、OpenCode 都能用 Lead，手机上作答后会自动继续
- 签验收时签下的是当时看到的验收项，每一项都能查到证据
- 关卡卡片和 Lead 面板重做，能看出任务进行到哪一步

## 手机

- 可以切换账号、查看用量，排队的消息能用手指拖动排序

## 其他改进

- Windows 上又能把文件拖进输入框
- 改动卡里的文件可以展开，查看这一轮的每次修改
- 「更改」面板列出本会话建过、动过的 PR
- 面板浏览器支持人工接管，回复里的截图可以点开看大图

## 修复

- Kimi 新会话的第一条消息能发出，不支持的图片不再让会话卡住
- Windows 11 深色模式下窗口底色不再发灰
