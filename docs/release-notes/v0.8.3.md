这一版换了新外观，并且能在 Meowo 里从开工走到合并：新建会话时开 worktree，在「更改」面板里推送、开 PR、看 CI、合并。

## 从开工到合并

- 新建会话可以勾选「在新 worktree 里开」，Meowo 建好分支并复制 `.env` 文件
- 「更改」面板能推送、开 PR、看 CI 结果和合并，手机页也能用
- 侧栏的会话行显示 PR 编号、CI 状态和未提交的增删行数

## 新外观

- 强调色换成青柠，状态色更好区分
- Windows 11 上窗口用 Mica 半透明材质，macOS 用系统材质
- 设置、引导、更新、新建会话等窗口都重新排过

## 改进

- Alt+Shift+↓ 跳到下一个等你处理或出错的会话
- Ctrl+K 能搜会话，也能切模型、开 PR、用编辑器打开
- 长会话打开更快
- 放弃更改时，未跟踪的文件移到回收站
- CLI 意外退出时会提醒，对话页写明退出原因
- 灵动岛上点提醒直接打开会话，审批和出错的提醒排在前面
- 面板浏览器支持下载，网页请求摄像头等权限时会先问你
- Lead 关卡新增授权类型，访谈问题在手机上也能答

## 修复

- 个别消息导致窗口白屏或卡死
- 窗口拉矮时看不到审批卡里的命令和选项
- 手机上关卡卡片滑不到提交按钮
- 已看过的会话一直亮未读点
- 自己写的 Kimi MCP 配置被覆盖
- 检查或下载更新卡住不动
