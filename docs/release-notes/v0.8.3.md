这一版换了一套外观：强调色改成青柠，Windows 11 的窗口用上 Mica 材质，每个窗口都重新排过。从开工到合并也能在 Meowo 里走完：新建会话时建 worktree，在「更改」面板里推送、开 PR、看 CI、合并。另外，多个会话之间切换更快，长会话打开更快，放弃更改改为进回收站。

## 新外观

- 强调色从蓝色换成青柠，灰色换成纯中性灰。运行、等待、出错三种状态色重新取值，红绿色盲视觉下更容易分开
- 侧栏和标题行坐在窗口底上，对话和右侧面板合成一张圆角卡
- Windows 11 的对话窗、设置、引导、更新、新建会话窗用 Mica 材质。系统关了透明效果或在 Windows 10 上是实色。macOS 的对话窗和设置窗用系统材质
- 设置、引导、更新窗、确认框、新建会话页都重新排过，引导第 2、3 步补了示意图
- 应用图标的眼睛换成青柠。灵动岛提醒里的主按钮跟着换色，眼睛、状态环和时钟没变
- 按钮、菜单、图标收成一套样式，图标线宽和尺寸统一

## 从开工到合并

- 新建会话可以勾选「在新 worktree 里开」，默认不勾。勾上后会建分支 `meowo/<用途>`，worktree 放在仓库旁边，并把被 git 忽略的 `.env*` 复制过去
- 仓库里写了 `.meowo/worktree.json` 时，会在后台跑其中的准备脚本，会话页能看进度和日志，可以跳过或重跑。脚本第一次运行前先给你看原文，确认后才跑
- worktree 会话在侧栏和灵动岛归到原项目下，组内标出 worktree 名
- 「更改」面板能推送，显示还有几个提交没推。分支没有上游时自动设上
- 「更改」面板能开 PR。装了 gh 时标题和正文预填，没装时打开 GitHub 的新建 PR 网页
- 开了 PR 后逐项显示 CI 结果，可以在面板里合并。CI 没全过、有冲突或是草稿时不能合并，并写明原因
- 合并后提示清理 worktree。没装 gh 也能清理已合并的 worktree
- 侧栏的会话行显示 PR 编号、CI 状态和未提交的增删行数
- 以上在手机页也能做，合并多一道确认

## 「更改」面板

- 放弃更改时，未跟踪的文件移到回收站。移不进时报错，文件留在原处
- 未跟踪文件超过 50 个的目录折成一行，可以点开，也可以整个目录暂存、放弃或「加入 .gitignore」
- 行内的放弃、暂存图标按列对齐，增删行数右对齐
- 会话开在仓库子目录时，未跟踪文件的行数按实际算，点开能看到内容

## 多会话切换

- Alt+Shift+↓ 跳到下一个待批准、待回答或出错的会话，到头循环
- Ctrl+K 打开时默认选中下一个会话，行尾显示未读点。还能切面板页签、切模型和权限模式、打开 PR、用编辑器打开
- Ctrl+F 在对话和终端里都是在当前内容里找字，搜会话用 Ctrl+K
- 侧栏可以用 Ctrl+Shift+↑/↓ 调整会话顺序
- 系统通知可以按种类开关
- CLI 意外退出时会提醒并发系统通知，对话页写明退出码和最后几行输出

## 灵动岛

- 提醒显示时点岛的正文，打开那个会话。排在后面的提醒照常弹出
- 审批、提问、出错的提醒排到最前面
- 提醒可以单条关掉，也可以「全部忽略」
- 最大化窗口在前台时岛收成细条，光标靠近时恢复。设置里可以关，仅 Windows
- 收起时的「+N」和分页圆点按其中最急的会话上色

## 对话窗

- 窗口拉窄、拉矮或审批卡出现时，输入框始终看得见。对话区至少保留 320 宽
- 窄窗下页签、模型和权限按钮只留图标，标题栏放不下的按钮收进「⋯」菜单
- 长会话首次打开和「加载更早」都更快。窗口隐藏时停掉后台轮询
- Claude Code 的终端停在子代理页时，从对话页发消息、中断、撤回都会先切回主会话。切不回时消息退回输入框，并提示「切回主会话」
- 用 claude 撤回消息时，终端里没发出去的草稿会接进对话页的输入框，再照常撤回
- 子任务交了结论但后台还在跑时，显示「已完成」和「后台仍在运行」
- Hook 的反馈显示成一行「Hook 反馈」，不再显示成你发的消息
- 焦点框更清楚，浅色主题的状态文字对比度提高。侧栏、后台任务、Lead 面板的页签支持方向键
- 系统开了「减少动效」时，转圈有静态替代

## 面板浏览器

- 下载有提示：正在下载、已下载或下载失败。下载完成后可以「打开文件夹」。文件重名时自动加编号
- 网页要下载多个文件、摄像头、麦克风、位置、通知权限时，在面板里问「阻止」还是「允许」。选择只对这一次有效
- 面板收起或页签不在前台时，有网页在等你允许会亮一个琥珀色圆点

## Lead 工作流

- 新增授权关卡，用于部署、花钱这类要先问的事，以及要你亲手做的事。可以答允许、我已完成或不允许
- 访谈问题改成卡片，手机上也能答，没有合适选项时可以只写文字
- 验收项可以豁免。豁免项排在最后并显示原因，不计入进度

## 手机页

- 会话列表改成大标题加卡片，底部是浮动导航，设置收成一屏
- 窄屏手机也能进「更改」。横屏一屏能看到 4 个会话
- 粘贴「复制地址」拿到的链接就能配对
- 输入框聚焦时 iOS 不再把整页放大

## 修复

- 一条异常消息（嵌套很深、表格很大）会让窗口白屏或卡死。现在这条消息退回原文显示
- 面板终端里有程序在跑时，关对话窗和从托盘退出都会先确认。退出和更新重启时会收掉面板终端
- 面板收起时 agent 操作的网页视口只有 2×2，截图超时
- 灵动岛面板上连点两次「新建会话」会开出两个窗口
- 手机上关卡卡片超出屏幕，展开摘要后滑不到选项和提交按钮
- 窗口拉矮时审批、提问和关卡卡片看不到命令和选项。现在先显示命令和选项，其余在卡片里滚动
- Lead 等停靠面板展开时盖住标题栏
- 恢复会话后 Lead 带回的是别的会话的任务
- 子任务徽标提前显示完成，或一直显示运行中
- 发给子代理的消息一直显示「未确认送达」
- 看过或已结束的会话一直亮未读点
- 对话页折叠起来的系统记录没对齐，顺序和原文不一致
- 用户自己写的 kimi MCP 配置被覆盖
- 检查更新和下载更新卡住时一直等。现在会超时，下一轮自动重试
