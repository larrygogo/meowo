这一版换了新外观，并且能在 Meowo 里从开工走到合并：新建会话时开 worktree，在「更改」面板里推送、开 PR、看 CI、合并。

## 从开工到合并

- 新建会话可以勾选「在新 worktree 里开」，Meowo 建好分支并复制 `.env` 文件
- 「更改」面板能推送、开 PR、看 CI 结果和合并，手机页也能用
- 侧栏的会话行显示 PR 编号、CI 状态和未提交的增删行数

## 新外观

- 强调色换成青柠，Windows 11 上窗口用 Mica 半透明材质
- 手机页改成大标题加卡片，粘贴「复制地址」的链接就能配对

## 改进

- Alt+Shift+↓ 跳到下一个等你处理或出错的会话
- Ctrl+K 能搜会话、切模型、开 PR，Ctrl+F 改为在当前内容里找字
- 长会话打开更快
- 放弃更改时，未跟踪的文件移到回收站
- CLI 意外退出时会提醒，对话页显示退出码和最后几行输出
- 点灵动岛上的提醒就能打开会话，审批和出错的提醒排在前面
- 最大化窗口在前台时，灵动岛收成细条，设置里可以关
- 面板浏览器下载文件时有提示，网页要权限时先问你
- 面板终端里有程序在跑时，关窗或退出会先确认

## 修复

- 个别消息不再让窗口白屏或卡死
- 窗口拉矮时也能看到审批卡里的命令和选项
- 手机上的关卡卡片能滑到提交按钮
- 看过的会话不再一直亮未读点
- 自己写的 Kimi MCP 配置不再被覆盖
- 检查或下载更新卡住时会自动重试
