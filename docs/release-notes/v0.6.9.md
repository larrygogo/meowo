这一版修两个「看起来好了、其实没好」的地方：切账号重启后终端页定格不动，以及在对话窗里替 Agent 回答问题时，Agent 反而起了疑心、停下来反问你。另外对话内容的宽度可以选了。

## 在对话窗作答，Agent 不再怀疑答案

- **此前的问题**：在对话窗的提问卡里作答后，Claude Code 收到的是一条红色的 `Error: 【Meowo 代答】用户已…请勿重试提问，直接采用以下答案`。这段话出现在工具结果里、自称代表你、还带着指令——正是提示注入的典型样子，模型会（也应当）不信它，转而停下来问你「这是你本人的选择吗？」
- **本版改法**：答案不再塞进「拒绝」的理由里，而是按 Claude Code 自己终端表单的方式交回去——工具正常返回你的选择，没有报错、没有指令性文字，Agent 直接接着干
- 提交的答案会和当时的题面逐题核对（不多不漏）；少数没法按题面区分的提问（空题面、两题同文）不在卡片里作答，提示去终端作答，不会送出错位的答案
- 旧会话里此前的代答回执照旧显示为「已作答」

## 切账号重启后，终端页不再定格

- 0.6.8 的「切账号即时作用于运行中的会话」重启了进程，但开着的对话窗/终端页不知道进程换了代：新进程的输出被当成「已经显示过」整段丢掉，画面停在旧进程最后一帧，打字也没有回显
- 本版在这种由设置窗发起的重启后通知持有画面的窗口复位，新进程的输出照常上屏

## 对话内容宽度可选

- 设置 → 外观新增「对话内容宽度」：**定宽**（默认，居中的阅读列，和以前一样）或**铺满**整个窗口
- 消息、输入框、审批卡、排队提示与运行条一起切换，改完即时生效
