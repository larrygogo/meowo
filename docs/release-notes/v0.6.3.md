这一版让后台的活儿看得见：fork 出去跑的子任务和后台命令都会列在进度面板里，它们在跑时会话不再显示「等你输入」。

## 子任务与后台任务

- `/code-review` 这类 fork 出去跑的 skill，派出的子任务会显示在进度面板
- 后台命令还在跑时，会话不再显示「等你输入」，进度面板也会列出它
- 同一条命令跑过多次时，展开的子任务不再对错
- fork 出去的 skill 跑完后不再一直显示「运行中」

## 改进

- 长会话输出时、侧栏有几百条会话时更流畅
- 会话空闲和结束后，后台开销更小

## 修复

- 退出 agent 后，终端一动鼠标不再刷字符，外部终端也一样
- Shift+滚轮在 Claude 全屏界面下能滚动了
- 切换模型后马上关窗，不再打断正在跑的回合
- 托盘右键菜单打开窗口不再白屏卡顿
- Windows 上「重启并更新」后，托管的会话不再留在后台
- 用量里 Opus 那一条不再消失，贴纸的模型周限显示用得最满的一条
- macOS 上贴纸窗能拖边框，Dock 图标不再一直留着
- macOS 上路径很长时，会话状态和终端聚焦恢复正常
- 修复了几个安全问题，建议更新
