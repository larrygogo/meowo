这一版让聊过的内容能找回来：侧栏能全文搜索对话，终端能按 Ctrl+F 搜索。后台子任务的状态更准了，更新会在你退出时静默装好。

## 搜索

- 侧栏「搜索对话内容」能搜最近 200 个会话的记录，包括已归档的，点结果跳到会话
- 搜会话时也会匹配便签和最近的往来消息
- 切换页签不再丢搜索词

## 终端与输入

- 终端支持 Ctrl+F 搜索，emoji 不再被裁掉一半
- 文件拖进对话框就成了附件，输入 @ 能补全文件路径
- 按 ↑ 取回上一条发过的消息，草稿按会话各自保存
- 对话里的代码块有语法高亮，消息带日期分隔，悬停能看精确时间

## 改进

- 更新下载好后点「稍后」，退出 Meowo 时会静默安装，不再弹进度窗口
- 主回合结束但后台子任务还在跑时，显示为后台忙碌，不再标成等待中
- 在外部终端跑的会话，提问和审批留在终端里作答
- AI 用 /clear 开新会话时，看板合成一张卡，开着的对话窗跟到新的一段
- 可以按住 Ctrl 点选多个会话批量归档

## 修复

- 后台子任务完成后，状态不再一直停在「进行中」
- 同一回合不再重复弹「等待你回复」通知
- Claude Code 新版标题动画下，运行中的会话不再被误判
- GBK 编码的文件不再满屏乱码
- 长会话不再越聊越卡
- 修复了几个安全问题，建议更新

## 注意

- 审批卡上按 Esc 拒绝改为两步确认
