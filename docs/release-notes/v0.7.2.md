这一版主要改进手机页：能拖动排序，能在手机上开关电脑的防休眠和推送。设置里新增「扩展」页，可以看各 agent 装了哪些技能和 MCP 服务。

## 手机页

- 长按会话后拖动可以调整顺序，和电脑同步
- 右上角新增设置，能开关电脑的防休眠和推送
- 推送可以暂停，链接保留

## 改进

- 新增「扩展」页，集中查看各 agent 的技能、MCP 服务、命令和插件
- 登录失效时提示去登录，并给出「去登录」按钮
- 新增「消息自动折叠」，回复结束后只露最终回答
- 新增「通知提示音」开关
- 托盘退出时，有会话在跑会先确认
- 窗口变窄时标题栏优先保留会话标题

## 修复

- 子任务展开后一层套一层地出现它自己
- 子代理被续上后仍显示已完成
- Claude 跑 /loop 时两轮之间误报「等你回复」
- 英文界面下错误标题显示成中文
