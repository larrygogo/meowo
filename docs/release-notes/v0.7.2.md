这一版主要补手机端和几处容易卡住的地方。手机上能拖动排序、能开关电脑的防休眠和推送；fork 子任务不再无限嵌套，被续上的子代理会重新显示为运行中；托盘退出、登录失效、/loop 空档这几处不再让人摸不着头脑。设置里新增「扩展」页，可以集中查看各 agent 装了什么。

## 手机页

- 长按会话或工作区分组后拖动，可以调整顺序，和电脑上的排序同步。长按不拖则弹出会话菜单
- 会话列表右上角新增设置面板：主题、消息自动折叠只对这台手机生效；电脑的「运行时防止休眠」和「推送到手机」可以直接开关
- 电脑端「推送到手机」新增暂停开关，暂停后不推送，链接保留

## 子任务与状态

- fork 类型的子任务展开后，里面不再一层套一层地出现它自己
- 子代理跑完后被主 agent 用 SendMessage 续上时，对话页、底部「子代理」面板和看板卡片会重新显示运行中，跑完再变回完成
- Claude 跑 /loop 时，两轮之间的空档不再当成「等你回复」，不弹通知，卡片保持运行中
- Codex、Kimi、opencode 会话改用 agent 自己起的标题

## 对话窗

- 回合出错时写清下一步：登录失效提示先登录，并给「去登录」按钮直达账号页；连不上 API 时提示检查网络或代理。「未登录」和「组织关闭了订阅访问」两种报错此前认不出，会话会静静停着
- 英文界面下，出错卡和看板卡片的错误标题不再显示中文
- 窗口变窄时，标题栏先保会话标题，PR 状态、分支名、项目名、「用编辑器打开」按顺序收起
- 会话在外部终端运行时，输入框上方的接管提示收成一行，按钮改成「结束并接管」
- 侧栏收起或变成抽屉时，对话区贴边铺满，不再留左上圆角
- 窗口左上角加上 Meowo logo
- 新增「消息自动折叠」（外观页，默认关）：回复结束后把思考和工具调用收成一行，只露最终回答

## 设置

- 新增「扩展」页，集中查看各 agent 装的技能、MCP 服务、自定义命令、钩子和插件。只读，不显示 MCP 参数、环境变量和钩子命令
- 扩展页点文件夹图标，对装成目录联接的技能（如 lark 系列）不再报「路径超出工作目录」
- 新增「通知提示音」开关（默认开）。关掉后系统通知照弹，但不响

## 其它

- 托盘「退出」在有托管会话正在运行时先确认一下，写明会中断几个会话。没有在跑的会话时照旧直接退出
- e2e 测试跟上 Tauri 2.12，CI 改用 Node 26
