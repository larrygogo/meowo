这是一个试用版，自动更新不会推送它，要手动下载安装。打开 Meowo 的第一屏从「侧栏 + 一个对话」换成了一张 agent 名单：每行一个 agent，写着它此刻在做什么。轮到你的事（审批、提问、Lead 关卡、出错）点开那一行就能原位处理，不用先进那个会话。

## 名单

- 主窗口首屏是名单，按创建时间排，状态变化不重排。置顶和手动拖拽照旧
- 每行有头像与状态环、任务名、项目、状态词、此刻在做什么、多久之前、未提交的增删行数
- 点一行展开：最近几步、它最后说的话；出错的行带错误原文
- 只开了一个会话时，打开就是它的现场
- 顶部右端是「已完成」「会话管理」「搜索」和设置。名单上按 Ctrl+K 也能搜
- 双击一行或点「进入现场」是原来完整的对话窗，现场顶栏上有「回到名单」

## 在行内处理

- 审批：允许一次、拒绝、说明并拒绝。危险命令的允许钮标红。名单上按 Esc 只收起这一行，不会拒绝
- Claude 的提问：在行内选好答案提交，agent 直接继续
- Lead 关卡：在行内选项并提交
- 答不了的情况如实说明。Meowo 托管着终端的，行内给终端画面和按键；在外部终端里跑的，给「跳到终端」和「接管到 Meowo」
- 出错的行：还在跑的给「继续」，CLI 已退出的给「恢复」
- 点开一行后，底部输入框指向它，回车就把话发给它，人留在名单上。发不出去时（比如它正停在审批上）会亮出现场说明原因

## 其他变化

- 名单在眼前且窗口在前台时，不再弹系统通知
- 侧栏去掉了「按最近活动」排序，只按你自己排的顺序
- 手机页的「会话」默认也是名单，行内能批准、拒绝、作答。手机和桌面都能答同一条审批，先答的生效，后答的那边显示「已在别处处理」。原来的会话列表在「全部会话」里
- 小窗口加大界面缩放时，审批卡至少露出命令，不会只剩按钮

## 试用须知

- 装上这个版本会替换已装的稳定版，数据不受影响。要回到稳定版，重新下载安装 0.8.3
- 装了试用版以后，不会自动收到下一个试用版，要手动装。0.9.0 正式版发布后会照常自动更新过去
- 在名单上对 agent 说话时，Meowo 会切到那条会话等 1.5 秒再发。如果你发现话被打进了一个正在等审批的终端，请反馈
