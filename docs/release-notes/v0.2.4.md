这一版专门修稳定性，重点是卡顿卡死、会话状态丢失和界面不同步。

## 卡顿和卡死

- Windows 上第一次恢复已断开的会话时，贴纸不再冻住几秒
- macOS 上弹出「自动化」授权时，应用不再卡死
- 会话多、记录大时界面不再掉帧
- macOS 启动时不再闪一下贴纸窗口

## 会话状态

- 多个会话同时启动时，会话状态不再丢失
- 不再出现有会话却没有卡片，之后一直收不到它状态的情况
- 活跃的新会话不再被误标为「已断开」
- 贴纸不再停在旧状态等很久才刷新
- 设置文件不会因写到一半而损坏
- 上下文百分比不再偶尔消失
- 对话里引用了错误文字时，不再被误判为会话出错

## 界面

- 更新下载失败后可以重试，不再一直显示「更新中…」
- 拿不到更新包大小时显示「下载中…」，不再停在 0%
- 卡片上的「X 分钟前」每分钟刷新
- 用量快重置时显示「即将重置」，账号区用量不再被旧数据覆盖
- macOS 上「关于」页的链接能打开
- 长时间运行更稳，内存占用不再一直涨
