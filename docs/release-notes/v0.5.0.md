项目从 cc-kanban 改名为 Meowo。AI CLI 的安装、登录和新建会话都能在应用里完成，不用再回终端敲命令。

## 安装和登录 AI CLI

- 设置的「模型」页改成 agent 卡片，显示未安装、未登录或已登录
- 没装的 agent 点「安装」，卡片上显示进度，装完自动刷新
- 点「登录」拉起终端完成授权，等待中可以随时取消
- 安装和登录后自动接好 hooks，不用再手动点「修复连接」
- Claude 和 Codex 不再因为网站人机校验装不上

## 新建会话

- 贴纸底栏的「新建会话」打开新窗口，选目录和 agent 就能启动
- 目录选择器里能挑最近打开过的目录
- 设置里可以指定默认 agent

## 改进

- Kimi 和 Codex 会话也显示 Context 已用百分比
- Kimi 会话支持「待交互」状态
- 会话列表不再只显示 20 条，搜索覆盖当前标签页下的全部会话
- macOS 菜单栏图标改成带数字的徽章，橙色是运行中，黄色是待交互
- 没有活跃会话时，吸边缩略条显示两只会眨眼的眼睛
- 托盘菜单和「关于」页加了官网 meowo.io 的入口

## 修复

- 空闲时贴纸列表不再反复刷新抖动
- 新建的会话不再被误判为已断开并沉到底部

## 注意

- 应用和安装包改名为 Meowo，安装包文件名随之变化。应用内自动更新照常升级
