这一版开始支持 macOS 14 及以上，Intel 和 Apple Silicon 共用一个安装包。恢复已断开的会话时，也可以选用哪个终端。

## macOS

- 常驻菜单栏，不占 Dock。左键开关贴纸面板，右键打开「设置」「退出」菜单
- 菜单栏图标显示运行中和待交互的会话数，全部空闲时只显示图标
- 贴纸面板弹出时不抢当前应用的焦点，点面板外自动收起，全屏应用里也能弹
- 点连接中的会话，切到它所在的 Terminal 或 iTerm2 窗口和标签页
- 点已断开的会话，新开终端回到原项目目录，续上对话
- 会话等你回复或出错时发系统通知，点通知切到对应终端
- 账号用量从钥匙串读取登录信息，过期时自动续期
- 支持应用内检查更新和升级

## 新功能

- 设置新增「未连接会话打开终端」，可选 Windows Terminal、PowerShell、命令提示符，或 Terminal、iTerm2

## 改进

- 「运行中」的图标换成循环箭头，和 macOS 菜单栏一致

## 注意

- macOS 上第一次点卡片跳转或恢复终端时，要在系统设置的「自动化」里允许控制 Terminal 或 iTerm2
- macOS 上第一条通知会请求通知权限
