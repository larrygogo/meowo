这一版修三个对话窗里的小毛病：在终端里粘贴的图片对话里看不到；点开大图时长截图下半截被切掉；终端输入行里没发出去的文字，会被对话窗发出的消息一起带走。

## 终端里粘贴的图片，对话里也能看到了

- **此前的问题**：在终端页用 Ctrl-V 贴图后，对话里只剩 `[Image #1]` 这样的占位文字，图不见了；从对话窗输入框发的图却正常
- **原因**：Claude Code 把终端贴图的图片内嵌在记录里，Meowo 此前没解析这部分，只靠另一条指向 Claude Code 图片缓存的路径显示。而多账号下这个缓存目录 Meowo 读不到，Claude Code 过后也会把缓存清掉，历史里的图迟早都会失效
- **本版改法**：直接从记录里取出图片存成本地副本，和文字显示在同一个气泡里；缓存被清也不影响
- 从对话窗输入框发的图，现在也和文字显示在同一个气泡里（以前是在气泡下方单独一行）

## 点开大图，初始就能看全

- 点开图片预览时，长截图这类很高的图以前按原尺寸铺开，下半截被切掉，得先缩小才能看全
- 现在打开时整张图缩放到窗口内居中显示；本来就比窗口小的图保持原尺寸。滚轮缩放、拖拽、双击复位照旧

## 对话窗发消息，不再带走终端里没发的文字（#72）

- **此前的问题**：在终端输入行里打了字但没回车，再从对话窗发消息，发出去的内容会把终端里那段文字拼在前面
- **本版改法**：发送前先看一眼终端输入行，有没发出的文字就先用 Claude Code 自带的暂存功能（Ctrl-S）收起来，发完后 Claude Code 自动放回去——终端里的内容原样还在，也不会混进消息。输入行是空的就什么也不按，发送不会变慢
- 目前只对 Claude Code 生效，其它 Agent 的暂存方式还没实测，行为不变
- 已知限制：如果你在终端里用 Ctrl-S 手动暂存过内容、输入行里又留了新文字，再从对话窗发送，旧的暂存会被新文字替换（Claude Code 只存一份）
