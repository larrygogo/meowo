这一版新增代理设置，并修复了新建会话、拉起终端和会话状态的几处问题。

## 代理设置

- 设置里新增「网络」页，统一管理 Meowo 和各 agent 的代理
- 可选直连、跟随系统环境变量或自定义代理
- Claude Code、Codex、Kimi Code 可以各用各的代理
- 支持 HTTP、SOCKS5 和带账号密码的代理地址
- 能识别 `host:port:user:pass` 格式的代理地址
- 查用量、安装 AI CLI 和检查更新都走对应代理
- 保存时检查配置是否兼容，没生效的会写明原因

## 修复

- Windows 新建会话不再一次打开多个终端窗口
- Codex 安装路径变化后，不再提示「系统找不到指定的文件」
- Windows Terminal、macOS Terminal 和 iTerm2 的启动和切换更稳
- 已断开的会话不再显示为「待交互」，恢复后的排序更准
- Codex 的周配额不再被标成 5 小时配额
- 各 agent 的配置兼容性和出错提示更好

## 注意

- Codex 和 Kimi Code 的代理只对 Meowo 拉起的会话生效，界面上会写明范围
- Windows 卸载时会清理 Meowo 写入的集成配置
