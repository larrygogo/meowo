这一版能在手机上看会话、回消息、批审批了。一个会话也能同时访问多个仓库。Claude 的选择题提问可以在对话窗里作答。

## 手机远程

- 设置里开启「远程访问」，手机扫码配对，在浏览器里打开会话列表和对话
- 手机上能看时间线、发消息、批准或拒绝审批
- 手机在看时审批先送到手机，手机离线时回到桌面或终端，不会丢
- 手机也能新建会话，在页面里逐级选目录

## 一个会话，多个仓库

- 新建会话时点「+ 附加目录」或 Ctrl+点击最近目录，把别的仓库加进来
- 已有会话可以在「查看改动」面板的仓库菜单里附加或移除目录
- 断线重连、重启后附加的目录还在
- 「查看改动」面板能切到任一附加仓库，看文件和 diff
- 跨仓会话在贴纸和侧栏上标「+N」，悬停能看全部目录
- 目前只有 Claude Code 支持，其他 agent 不显示入口

## 选择题提问

- Claude 的提问在对话窗弹出作答卡片，支持多题、多选和自定义输入
- 想在终端答可以点「去终端作答」，关掉对话窗时提问会回到终端

## 修复

- 在对话窗作答后，时间线不再显示成红色失败块
- 终端正挂着审批或提问时，中途附加目录不会误选弹窗选项
- 英文界面补齐一批错误提示，贴纸和侧栏的徽标、菜单布局打磨
