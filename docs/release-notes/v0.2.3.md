这一版支持英文界面，在设置的「通用」里选「语言」，默认跟随系统。

## 新功能

- 界面、系统通知和托盘菜单支持中文和英文，切换后马上生效，不用重启

## 改进

- 待交互的图标统一为举手，运行中统一为循环箭头
- 应用图标里的蓝色换成品牌橙
- 原来中英混排的文字统一了，比如 Connected 改为「已连接」

## 修复

- 设置页在高缩放比例下开关不再歪
- 设置页描述太长时不再撑高整行
- 设置页靠近底部的下拉框空间不够时向上展开，不再被裁掉

## 注意

- 这一版内容和之前发布又撤回的 v0.3.0 相同。已升到 0.3.0 的不用改动，下个新版本发布后会照常收到更新
