这一版起看板不再只服务 Claude Code，新增 Kimi CLI 和 Codex CLI 支持，并带来账号与用量面板。

## 新功能

- 支持 Kimi CLI：会话自动上板，能恢复、重命名、写便签，点卡片切到对应终端标签（Windows）
- 支持 Codex CLI：会话接入看板，能恢复会话，点卡片切到对应终端标签
- 账号页每个 AI 一张卡，显示账号信息和用量配额，可以手动刷新
- 在账号卡开启「在贴纸显示配额」，贴纸底栏能切换查看各家的用量
- 新增贴纸样式和配色设置，配色可以用方向键挑选
- 可以从系统托盘找回贴纸窗口

## 修复

- Kimi 会话的连接状态更准，中途装上 hook 也能上板，恢复会话不再出错
- Codex 恢复会话不再提示找不到文件，点卡片不再跳错标签
- 恢复后的会话不再误显示为已连接
- 有多个同名终端标签时，点卡片能切到正确的那个
- 账号卡几处显示问题，Kimi 用量能正常读出
