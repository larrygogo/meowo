这一版让对话页更好用：截图显示成缩略图，工具调用收成一行，权限模式和模型可以从下拉里选。

## 对话页

- 粘贴的截图显示成缩略图，点开可以缩放和拖动
- 工具调用收起时只占一行，写明做了什么，展开看细节
- agent 一次问多个问题时分标签页显示，不再挤掉输入框
- 权限模式改成下拉菜单，选哪个切到哪个
- 模型列表从 CLI 读取，CLI 升级后跟着变
- opencode 能选模型了

## 看板与侧栏

- 侧栏除了按目录，还能按日期或按状态分组
- 目录筛选里同名的文件夹会带上上级目录
- 长列表滚动时下拉菜单不再自己关掉
- 点侧栏顶部或标题栏能关掉已打开的菜单

## 更快

- 启动和开窗更快
- 几百上千条消息的长会话，回复过程中不再卡顿
- 后台占用更低，安装包略小

## 修复

- 开关自启动、点「官网」链接不再让所有窗口卡住转圈
- 对话窗和确认框不再出现打不开或失灵的情况
- 深色主题下停止按钮和用量圆环显示正常
- 运行中的长命令不再让卡片高度来回跳

## 注意

- 已归档的会话不再出现在看板上，在设置的「会话」里查看和放回
- Windows 首次运行提示「未知发布者」时，点「更多信息」再点「仍要运行」
