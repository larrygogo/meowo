Windows 上给 Claude Code 发图片恢复正常。对话页改成终端式排版，不用切到终端页也能看清过程。浅色主题也重新配了色。

## 终端式对话页

- 工具调用写成 `Bash(命令)` 这样，下一行是结果摘要，命令会露出几行输出
- 编辑文件的 diff 按真实行号显示，带上下文
- 展开的命令和输出放在终端底色的框里，分色显示，不再出现乱码
- 工具调用展开成时间线，运行中的那一步显示已经跑了多久
- 每轮回复前写上 agent、模型和时间
- 运行条显示终端底部的状态行和最近一条命令
- 空会话显示欢迎面板，有 agent 版本、分支和几个起手入口
- 代码块顶部常驻语言标签和复制按钮
- 手机远程页同步了这些样式

## 改进
