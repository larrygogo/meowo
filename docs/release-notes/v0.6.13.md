这一版修了 Windows 上给 claude 发图片必定失败的问题，并把对话页换成了更像终端的样子：工具调用、改动的 diff、命令输出都按终端的写法排，不用再切到终端页看过程。浅色主题也重新配了色，不那么刺眼了。

## Windows 上给 claude 发图片失败（#83）

- **此前的问题**：在对话窗给 claude 发图片，一定报「图片附加未完成」，会话被锁住，要去终端页清理后才能继续。0.6.11 起稳定复现
- **原因**：claude 在 Windows 上的贴图键是 Alt+V，Meowo 一直发 Ctrl-V，claude 收到后什么也不做。0.6.11 之前没人发现，是因为失败后会悄悄改用文字指令让 claude 自己读图
- **本版改法**：贴图键由各 agent 按平台声明，Windows 上给 claude 发 Alt+V。终端页里粘贴截图也改用同一个键
- kimi 原来在所有平台都发 Alt+V，现在 macOS 上改发 Ctrl-V

## 对话页改成终端式排版（#83）

- **工具调用**：首行写成 `Update(src/a.ts)`、`Bash(命令)`，工具名按类型上色，会话目录下的路径显示成相对路径。第二行用 `⎿` 写结果，比如「新增 3 行，删除 1 行」「读取了 160 行」，命令会露出输出的头 3 行
- **改动的 diff**：编辑文件时按真实行号显示，增删交错，带上下文，和终端里看到的一样
- **展开后的命令和输出**：放进一个终端底色的框里。命令按命令名、参数、字符串、操作符分色；输出里的 diff 增删行、error、warning 行单独上色。此前输出里会出现「□[2m」这样的乱码，现在没有了
- **过程默认展开**：每一组工具调用默认展开成一条时间线，状态点分完成、进行中（会转）、失败三种。运行中的那一步会显示已经跑了多久
- **回合署名**：每轮回复前写上 agent 图标、名称、模型和时间
- **运行条**：照搬终端底部的状态行，比如 `Composing… (41s · ↓ 427 tokens)`。会话跑在外部终端时读不到这一行，就显示本轮已跑了多久。下一行是最近一条命令
- **空会话**：不再只有一行「还没有可显示的对话记录」，改成一个欢迎面板，写着 agent 版本、模型、分支和未提交的改动数，下面有几个起手入口，点了只往输入框里填，不会直接发出去
- **其它**：代码块顶部常驻语言标签和复制按钮；标题加重；行内代码、你发的消息、发送按钮改用主题绿

## 浅色主题重新配色（#83）

- 底色从偏冷的纯白纯灰换成略带暖调的米白，卡片、代码框、菜单跟着调整
- 工具名不再是一排高饱和的彩色，换成一套柔和的颜色，字也不那么粗
- 输入框的阴影淡了很多
- 调色后低于标准对比度的几种文字都压深了一档
