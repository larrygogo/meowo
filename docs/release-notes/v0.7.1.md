这一版对照 Kimi Code 把对话窗、侧栏和设置页重做了一遍。新建会话不再弹窗，在对话窗里写下第一句话就开聊；侧栏可以手动拖着排；标题栏能直接用编辑器打开项目、看分支和 Pull Request。另外，有会话在跑时电脑不会再睡过去。

## 新建会话

- 不再弹出小窗。点「新建会话」，对话窗右侧就换成新建页，写下第一句话回车，会话起来后这句话自动发进去
- 输入框上方选工作区，下面选 Agent、模型和权限，和对话页同一套样式
- 输入框下面列出这个工作区最近的几条会话，点一条直接回去接着聊
- 把文件夹拖进窗口，就设成新会话的工作区
- 贴纸、托盘等窗外入口也都打开对话窗的新建页。关掉对话功能（轻量模式）时仍是原来的小窗

## 侧栏

- 照 Kimi 重排：顶部是「新建会话」「搜索」，下面分「进行中 / 已完成 / 工作空间」三个页签
- 新增手动排序。会话和工作区分组都能按住拖动调位置，拖的时候有跟手的影子
- 「工作空间」页签列出用过的目录。点一行就在那里新建会话，右键可以只看这个工作区的会话，顶部可以添加新的工作区
- 视图与排序菜单收成两节：按工作区分组 / 不分组，手动排序 / 按最近活动
- 新增会话管理页（侧栏菜单最底下），可以按工作区、状态、更新时间筛选，批量标记完成或恢复

## 对话窗

- 标题栏左边是「项目 / 标题」，会话操作收进「⋯」。右边是用编辑器打开（自动找 VS Code、Cursor、Windsurf）、分支与改动、当前分支的 Pull Request、终端开关、侧边面板开关
- 会话菜单可以把整段对话复制成 Markdown，只复制最后一条回答，或者导出成 .md 文件
- 输入框的「+」改成菜单，可以加文件，也可以插入命令或提及文件。长提示词可以展开输入框来写
- 改动列表可以在列表和树形之间切换。文件页面板拉宽后，左边文件树、右边预览
- 右侧的消息目录展开时，所有标题一起露出，左对齐成一列
- 在已完成的会话里接着说话，它会自动回到「进行中」
- 对话窗默认宽度加到 1200，输入框圆角改得更柔和
- Agent 提问时，在对话页点选的答案能正确填进终端里的表单了
- CLI 收下排队的消息后会标「已排队」；「未确认送达」的消息可以直接提交或重发

## 设置

- 新增「运行时防止休眠」，默认开启。有会话在跑时电脑不会休眠，屏幕照常熄灭，会话都停下就恢复系统的设置。Windows 和 macOS 可用
- 「通用」「外观」按用途分组。手机远程单独成一栏，「网络」只留代理
- 「会话」里可以设新建会话的默认权限和默认模型
- 快捷键页改成和其它页一样的列表
- 报错改成带图标的提示块。远程端口被占时，提示贴在端口那一行
- 「已完成会话」改成打开会话管理页的入口

## 其它

- 双击托盘图标打开对话窗，不会再顺带把贴纸也开合一遍
- 会话管理页不再列出侧栏里看不到的后台会话
- 安装器各页内容垂直居中
- Tauri 升到 2.12，自动更新插件升到 2.14.1，修掉它解压用的 zip 库的高危漏洞（RUSTSEC-2026-0429）
