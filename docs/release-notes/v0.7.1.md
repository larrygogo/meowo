这一版重做了对话窗、侧栏和设置页。新建会话不再弹窗，在对话窗里写下第一句话就开始。有会话在跑时电脑不会休眠。

## 新建会话

- 点「新建会话」，对话窗里换成新建页，写下第一句话回车就开始
- 在同一页选工作区、Agent、模型和权限
- 下面列出这个工作区最近的会话，点一条接着聊
- 把文件夹拖进窗口就设成工作区

## 侧栏

- 分「进行中」「已完成」「工作空间」三个页签
- 会话和工作区分组可以拖动排序
- 新增会话管理页，可以筛选、批量标记完成

## 改进

- 新增「运行时防止休眠」，默认开启，屏幕照常熄灭
- 标题栏能用编辑器打开项目，能看分支和 Pull Request
- 对话可以复制成 Markdown 或导出成文件
- 在已完成的会话里接着说话，会自动回到「进行中」
- 可以设置新建会话的默认权限和模型

## 修复

- 在对话页选的答案能正确填进终端里的表单
- 双击托盘图标时贴纸不再跟着开合
- 手机页几处标题栏和图标的错位已修正
- 修复了一个安全问题，建议更新
