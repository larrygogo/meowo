这一版给对话页加了右侧的消息导航，长对话里能一键跳回自己问过的某句话。手机网页版现在能直接回答 agent 的提问，不用再回桌面端。另外修了运行中插话一发出就消失的问题，对话里也不再冒出 skill 说明、图片缩放说明这类写给模型的内容。

## 对话页右侧的消息导航（#87）

- 对话页右边一列短横线，你发的每条消息一根，当前读到的那条更长更亮
- 鼠标移上去展开成消息摘要列表，点一条就跳过去。斜杠命令前面带命令图标，连续发的几张图并成一项
- 列表最高 440 像素，消息多了在列表里滚动
- 手机网页版和很窄的窗口不显示

## 手机网页版可以直接答题（#87）

- **此前的问题**：agent 提问时，手机上的提问卡一律写着「请在桌面端作答」，看起来手机答不了
- **本版改法**：卡片里能答的题，点选后直接提交。卡片里答不了的题（比如两道题题面完全相同），点「转为逐题作答」，题目交回给终端里的表单，表单出现后作答卡会回到手机上
- 没有选项的开放题、提问卡超时后，提示改成「表单就绪后可在此作答」

## 运行中插话不再一发出就消失（#87）

- **此前的问题**：claude 正在干活时发一条消息，「插话已排队」的提示一闪就没了，对话里也看不到这条消息，像是没发出去
- **原因**：claude 2.1.304 在插话进队列的那一刻就通知了 Meowo，但要等当前工具跑完才真正把消息写进记录，中间可能隔几十秒。Meowo 把那次通知当成了「消息已处理」
- **本版改法**：对话里已经有记录时，只有消息真正出现在记录里，才撤掉排队提示

## 对话里不再出现写给模型的内容（#87）

- **调用 skill 后**：不再多出一大块技能说明，看起来像是你发的。skill 调用本身仍显示成一张工具卡
- **发大图后**：不再多出一条「[Image: original 2310x1152, displayed at …]」

和上一版一样，已经打开过的旧会话重新加载后也会变干净。

**测试底盘**：后端 cargo test 全量 1153 个用例通过，clippy `-D warnings` 干净；前端 893 个用例通过，类型检查通过。消息导航在开发版里实际操作过：从底部跳到 3 条不同的消息，都停在离顶部 16 像素的位置，当前项标得对。插话的时间差在真实的 claude 2.1.304 上测过：发出 0.1 秒后就收到通知，消息要等工具跑完才写进记录。skill 说明和图片缩放说明的识别规则，用本机最近的会话记录核对过，没有误伤其他内容。手机答题只有自动化测试，没在真手机上试过；macOS 没看过。
