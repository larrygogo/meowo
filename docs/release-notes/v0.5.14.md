这一版修好了 Windows 上终端跑着跑着就僵住的问题，升级安装也不再报「无法复制文件」。另外新增 Ctrl+K，随时切换会话。

## 新功能

- Ctrl+K 打开快速切换器，输入几个字跳到任意会话
- Claude 遇到 API 错误时，看板卡片标红、发桌面通知，对话页显示错误气泡
- 终端里选中文字时右键复制，没选中时右键粘贴
- Ctrl+Enter 和 Shift+Enter 也能换行，不会误发送

## 改进

- 终端输出停滞较久时会明确提示
- 会话卡死时，「结束会话」也能几秒内生效
- 看板状态点改回红绿灯：颜色表示状态，闪烁表示急不急。Agent 停在待操作界面时显示「待操作」
- 第二次启动 Meowo 时唤起已有窗口，不再开出两个实例
- 侧栏搜索框、图片查看、提示气泡等界面细节打磨

## 修复

- Windows 上会话不再跑着跑着画面定格、打字没反应
- 升级安装不再报「无法复制文件」
- 输入框不再偶尔出现两个光标，画面不再错乱重叠
- 恢复会话后发的第一条消息不再丢失，发不进去时会退回并提示
