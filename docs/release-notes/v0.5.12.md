这一版的权限模式会跟着会话走，接管和恢复不再重置。Windows 上的对话窗口用上了原生窗口按钮和分屏。

## 权限模式

- 新建会话时选的权限模式和模型会被记住，接管或恢复时自动带上
- 接管按钮旁有权限下拉，能现选这次恢复用的模式，包括「跳过权限确认」
- 休眠会话的权限胶囊可以预选下次恢复的模式

## 窗口（Windows）

- 右上角是系统的最小化、最大化和关闭，悬停最大化能选分屏布局
- agent 请求审批或提问时，对话窗口不再抢焦点，改为任务栏闪烁

## 对话页

- 点会话标题展开菜单，能置顶、打开目录、重命名和归档
- 粘贴的图片显示缩略图，文件显示成统一大小的卡片
- 后台任务的完成通知收成一行摘要，点开看全文
- `/code-review` 这类后台命令显示成命令徽章

## 侧栏

- 顶部换成「新建会话」入口，目录筛选和分组收进一个筛选面板
- 窗口拉窄时侧栏收起，需要时从边上滑出
- 长标题和临时目录名截短显示

## 修复

- 下拉菜单不再超出窗口，打开方向更合适
- 终端页签里的弹出菜单也是深色
- 提示气泡不再盖住下拉菜单
- 消息里单独一行的「-」不再被删掉

## 注意

- 对话页标题栏的徽标、路径和零散按钮去掉了，操作都在标题菜单里
