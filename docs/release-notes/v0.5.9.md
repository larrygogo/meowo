这一版的对话页能管理会话了：归档、置顶、重命名都在侧栏菜单里，侧栏还能按目录分组。

## 新功能

- 对话页标题栏能归档当前会话，归档后自动切到下一条
- 置顶、便签、重命名、归档、结束会话等菜单搬进对话页侧栏，和贴纸卡片一致
- Claude Code 的后台会话能在对话页看终端画面和发消息
- 其他账号能合并进默认账号，会话一并挂过去，有会话在跑时不能合并
- 侧栏能按工作目录分组和筛选，未运行的会话可以折叠
- `/clear` 这类命令在对话里显示成命令徽章，点开看输出

## 改进

- 置顶的会话排在侧栏最前
- 各类审批和选择卡片样式统一
- 排队的消息可以逐条移除，Ctrl+Enter 中断后发送，另有单独的「中断」按钮
- 点通知时，对话窗口里的会话打开对话窗口，外部终端的会话切到终端
- 侧栏的「⋯」按钮鼠标移上去才出现

## 修复

- 权限放行后，对话页不再一直显示「Agent 请求权限」
- 换账号恢复的会话，新消息能继续显示
- 在右键菜单里按 Esc 不再顺带拒绝审批
- 后台会话没接上时显示「重新接入」，不再误报已结束
- 后台会话没响应时，发消息不再一直卡住
- 已归档的会话不再出现在对话页侧栏

## 注意

- 「星标」改叫「置顶」，图标换成上箭头
- 后台会话不在看板上显示卡片
