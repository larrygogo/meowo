这一版修了对话页的几处显示问题和一个发图的老问题。claude 正在运行时发图片，不会再报「图片附加未完成」；发图失败一次之后，也不会再把后面的消息全拦住。对话里不再冒出 agent 写给模型的内容，比如压缩摘要、粘贴标签、kimi 的任务通知和技能说明。

## claude 运行中发图报错（#85）

- **此前的问题**：claude 正在干活时，在对话页发带图片的消息，一定报「图片附加未完成」，正文发不出去。其实图已经贴进 claude 的输入框了，是 Meowo 没认出来
- **原因**：claude 运行中只重画有变化的格子。占位符 `[Image #1]` 里那个空格，在上一帧本来就是空白，claude 就不输出它，直接把光标跳过去。Meowo 读到的是 `[Image#1]`，跟它要找的不一样
- **本版改法**：认占位符时空格可有可无。codex 用的是同一条规则，一起改了

## 发图失败后不再拦着发送（#85）

- **此前的问题**：发图失败一次之后，这个会话的每条消息都被拦下，要去终端页手动清理、再点确认，哪怕新消息根本没带图
- **本版改法**：发送前自动看一眼 claude 的输入框，有上次留下的残图就清掉，然后照常发送。原稿和附件一直留在对话页的输入框里，带图的消息会重新贴一次
- 认不出输入框时还是按原来的方式拦截。目前只有 claude 能自动清理，codex、kimi 维持原样

## 对话里不再出现写给模型的内容（#84、#86）

- **claude 压缩上下文后**：「上下文已压缩」分隔线下面不再多出一大块英文摘要
- **claude 粘贴文本**：前后不再露出 `<pasted_content id="…">` 两行标签
- **kimi 后台任务完成通知**：不再显示成一整段 XML
- **kimi 斜杠激活技能**：显示成你敲的 `/技能名`，不再摊开整份技能说明
- **kimi 带图消息**：正文里夹的 `<system>Image compressed…</system>` 压缩提示去掉了

这几处都是解析记录时处理的，已经打开过的旧会话重新加载后也会变干净。
