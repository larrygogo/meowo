这一版主要修两件事。一是 Gemini 刚启动时，在对话页发的消息会卡在它的输入框里发不出去，现在能正常发出。二是手机远程页跟上了上一版对话窗的改版：字号和桌面一样大，顶部少占一行，代码块能直接复制。

## Gemini 刚启动时对话页发不出消息（#80）

- **此前的问题**：给刚启动的 Gemini 会话发第一条消息，消息停在 Gemini 的输入框里，没有提交。0.6.11 上能稳定复现
- **原因**：Gemini 一启动，会话就被记成「运行中」，直到发第一条消息都没改回来。对话页以为它在忙，按了排队键 Tab，而 Gemini 空闲时按 Tab 不会提交
- **本版改法**：对话页判断会话是否在跑时，也参考终端屏幕，和侧栏、看板的判断一致。Gemini 的排队键也从 Tab 改成回车：它运行中按回车同样会排队，空闲时回车直接提交，就算状态判错，消息也不会卡住
- Codex 不受影响，仍按 Tab 排队

## 手机远程页跟上对话窗改版（#81）

上一版对话窗照 Kimi 的比例放大了字号，手机页没跟着调，有些字反倒比桌面还小。

- **字号和桌面一样大**：过程行 12→14px，工具组摘要 12→13px，你发的消息 14→15px，和 Agent 的回答一样大。输入框、模型按钮等手机上本来就放大过的地方保持不变
- **顶部省出一行**：手机竖屏上原来顶部占两行，第一行只有一个侧栏开关。现在开关并进会话标题这一行
- **去掉卡片外框**：手机竖屏上对话区不再套一层圆角卡片，内容贴边，多出约 14px 宽
- **代码块能直接复制**：此前「复制」按钮要先点一下代码块才出现，出来后还压住第一行代码。现在一直显示，代码顶部留出位置
- **输入框工具行不再挤**：此前模型名会被压成「O…」，权限按钮成了「权限…」。现在用量只显示圆环（环里有百分比），360px 宽的手机上也能完整显示「Opus」「权限模式」
- 侧栏每行的「⋯」去掉了灰色底块，只留图标
- 平板和电脑浏览器打开的远程页保持原样

## 其它

- CI 的依赖安全检查忽略 zip 4.6.1 的三条公告（RUSTSEC-2026-0367 ~ 0369）。zip 由更新插件引入，插件最新版仍锁在 zip 4，暂时升不了。这几条在 Meowo 里碰不到：zip 只在 Windows 上使用，公告讲的是 Unix 权限和 macOS/Linux 上的符号链接；更新包先验签名才解压，而且 Windows 更新包是安装程序本身，不经过 zip 解压（#82）
