这一版修好了手机上新建会话报错，Kimi 能发图了。审批卡改为悬浮，不再把输入框往下推。新增 Ctrl+K 命令面板，设置里能看各 agent 的版本并更新。

## 手机远程

- 新建会话不再报「参数无效」，建好后进入新会话
- 打开会话列表时不再每次闪「加载中」
- 点开一条审批通知，不再清掉其他会话的通知

## 图片附件

- Kimi 在 Windows 上能正常发图
- 运行中只发图片时，「（附件）」回执不再一直留着
- 会话标题不再变成附件说明之类的系统文本

## 对话窗

- 审批卡和提问卡悬浮显示，不再把输入框和消息往下推
- Ctrl+K 打开命令面板，能搜会话，也能新建会话、切视图、收起侧栏
- 设置里的界面缩放也作用于对话窗
- 消息不再偶尔显示两遍
- 「回到最新」按钮显示未读条数

## 看板与设置

- 已结束的会话不再被误报「待交互」
- 新任务开始时旧的待办清单自动折叠，进度只算当前任务
- 设置的 Agent 分区显示各家版本，有新版时能更新
- 设置搜索能搜到下拉选项里的内容
- 开了多个 Meowo 时，远程访问二维码也指向正确的那个

## 窗口与终端

- Windows 上把贴纸拖到屏边时，落点会画在屏幕边上
- 托盘单击能展开收成细条的贴纸
- 终端僵住时，「结束并恢复」也能一步完成
- 贴纸悬停展开时不再消失
