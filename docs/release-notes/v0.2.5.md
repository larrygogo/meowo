这一版让贴纸卡片更好用：卡片上能看到 AI 最近说了什么，重要会话可以加星置顶，还能给会话写便签。

## 新功能

- 卡片信息行显示 AI 最近一条回复，待交互时能看到它在等你确认什么
- 给会话加星，星标会话排在最前，重启后保留
- 给会话写一段便签，显示在卡片上，只存在本地
- Windows 上鼠标停在托盘图标上，能看到待交互和运行中的会话数
- 「待交互」里等得最久的会话排在前面
- 设置里可以选点卡片打开终端，还是点卡片上的「打开」按钮

## 改进

- 卡片上的星标、便签、改名、归档按钮在鼠标停上时才出现
- 改名和写便签时点卡片空白处只关掉编辑框，不会打开终端
- 改名和便签编辑框有保存和取消按钮

## 修复

- 不再误改你自己写的 Claude Code hook

## 注意

- 卡片信息行原来显示最近的 Bash 命令，现在改为 AI 最近的回复，设置里可以关
