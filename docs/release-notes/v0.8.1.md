这一版给对话窗加了右侧面板，改动、文件、终端、浏览器放在一排页签里。agent 能自己操作面板里的浏览器，你看得到它在点哪里。

## 右侧面板

- 改动、文件、终端、浏览器同在一排页签，可以拖动排序
- Ctrl+Shift+B、G、E 分别打开浏览器、改动、文件
- 每个会话记住自己开了哪些页签
- 对话里的 localhost 链接直接在面板浏览器里打开

## agent 操作浏览器

- Claude、Codex、Kimi 能在面板浏览器里打开网页、点击、输入和截图
- 页面上能看到 agent 的鼠标，你随时可以「接管」
- 设置里可以关掉

## 改进

- 灵动岛的眼睛多了十几种表情，跟着会话状态和额度变化
- 灵动岛上会话的顺序和侧栏一致
- 改动页的 diff 显示新旧行号
- 文件预览能自动换行、复制全文
