这一版给对话窗加了右侧面板：改动、文件、终端、浏览器放在同一排页签里，用法照 Kimi Code。agent 能自己操作面板里的浏览器，你看得到它的鼠标。灵动岛的眼睛多了十几种表情，岛上会话的顺序也和侧栏一致了。另外修了 kimi 换模型切不过去、终端和对话里的路径点不开等问题。

## 对话窗右侧面板

- 改动、文件、终端、浏览器同在一排页签里，可以拖动排序、右键关闭其它或右侧的页签。页签放不下时可以滚轮横向滚，也可以点「全部页签」跳到任意一个
- 快捷键：Ctrl+Shift+B 浏览器，Ctrl+Shift+G 改动，Ctrl+Shift+E 文件，Ctrl+\` 终端，Ctrl+T 新页签，Ctrl+W 关闭，Ctrl+Tab 切换
- 每个会话记住自己开了哪些页签、面板开着还是收着。会话结束或归档后，它开的终端和浏览器一起关掉
- 终端：在会话目录里开 PowerShell（macOS 是默认 shell），可以开多个。关掉还有程序在跑的终端时会先问一句
- 浏览器：地址栏、前进后退、缩放、打印。对话里的 localhost 链接直接在面板里打开
- 窗口够宽时，对话旁边多一栏会话信息：改动数、已打开的页签、可以打开的东西

## agent 操作面板浏览器

- claude、codex、kimi 会话启动时自动接上一组浏览器工具，agent 能打开网页、点击、输入、滚动、读页面内容、截图
- agent 操作时，页面上能看到它的鼠标移动和点击，页签上亮一个点
- 你随时可以点「接管」暂停它，用完点「交还」
- 设置里能关掉。关掉后正在跑的会话也立刻用不了

## 文件和改动页签

- 面板拉宽后，文件树变成侧栏：可以收起、放左边或右边、拖动调宽，都会记住
- 预览表头加了自动换行、复制全文、刷新。文件在后台被改了，「刷新」变成橙色，点了才换内容
- 树上的行悬停出「…」，和右键是同一份菜单。菜单里新加「添加到对话」，把路径插进输入框
- 压成一行的 JSON 自动展开成缩进格式
- 改动页的 diff 左边加了旧、新两列行号。改动页开着时每 5 秒刷新一次改动列表
- 没有改动时显示「工作区干净，无改动」

## 灵动岛

- 眼睛多了十几种表情：额度快用完时发愁、用光时转蚊香圈、同时跑 3 个以上时专注、闲久了犯困打哈欠、有会话刚跑完时星星眼、新开会话时吓一跳、两个以上出错时抓狂、待处理放久了可怜巴巴、鼠标停在岛上时害羞
- 睁着眼时隔一会儿自己眨一只眼或往旁边瞟一眼
- macOS 菜单栏图标和岛上是同一个表情
- 岛上的会话头像和展开面板里的列表，都和对话窗侧栏同一个顺序。置顶、排序方式、按工作区分组都跟着侧栏走

## 修复

- kimi 会话聊过几句后，在对话页换模型会转圈十几秒然后失败。现在能正常切换
- 托管终端里 Ctrl+点击会话目录外的路径（比如编出来的安装包）不再报「路径超出工作目录」。`~/…` 和 Git Bash 风格的 `/c/…` 也能点开
- 对话回复里反引号包着的路径和网址可以直接点。带行号的路径（`main.ts:42`）也能打开，打不开时链接后面会提示原因
- 选中对话文字时不再弹「引用」浮条
