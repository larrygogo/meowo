这一版新增对话窗口。点卡片就能看完整对话、发消息、处理审批，不用回终端。

## 对话窗口

- 点卡片打开对话窗口，实时显示对话、思考过程和工具调用，可以发消息
- 左侧栏浏览全部会话，滚到底自动加载更早的记录
- 会话断开后，在「终端」页签里恢复同一会话继续用
- 还在外部终端里跑的会话，可以「结束外部进程并接管」
- agent 请求权限时在窗口里允许或拒绝，计划和提问显示成可点选的卡片
- 子任务在对话里单独一行，展开能看它的过程
- 待办列表能从会话记录还原，历史会话也能看到

## 改进

- Gemini 支持用 API Key 登录
- 终端内置 JetBrains Mono 字体，各平台显示一致
- 长思考过程默认收起，展开后在框内滚动

## 修复

- 执行 `/clear` 后，旧会话也能正常接管
- macOS 对话窗口有了圆角，各窗口背景色统一
- 会话很少时，侧栏列表不再被压扁
- Kimi 已完成的待办不再变回待办
- 窗口打开时不再闪白框
- 终端里输入法或补全菜单打开时，回车能正常发送
- 审批、终端、登录和恢复会话的若干问题
