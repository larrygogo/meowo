这一版能看出 agent 停在终端提示前等你，Claude 的提问可以在对话页作答，终端字号和行高可以调。

## 新功能

- Meowo 里运行的会话会读终端画面判断状态，停在提示前等你时也能看出来
- Claude 提问时，题目和选项同步显示在对话页，单选题可以点选作答
- 多问题或多选的提问显示「去终端作答」
- agent 停下等你时会发通知，正在看的会话不打扰
- 设置新增「会话」分区，能调终端字号和行高，立即生效
- 贴纸底栏和 macOS 托盘菜单新增对话窗口入口
- macOS 恢复会话时可以选 Ghostty 做外部终端

## 改进

- macOS 对话窗口用系统原生标题栏
- macOS 上再次「在终端打开」会切到已开的窗口，不再新开一个
- 分组、归档等处的提示文字更简短

## 修复

- 在终端里答完信任提示后，对话页的卡片会收起，输入框恢复可用
- 在终端里取消或答完提问后，对话页的卡片会收起
- 几处 agent 状态判断错误
- 修复了一个安全问题，建议更新（Windows）
