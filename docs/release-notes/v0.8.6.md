这一版的设置窗按要找的事重新分组，提醒相关的开关都在新的「通知」页。轻量模式已去掉，对话窗口始终可用。Claude 提问时的题目卡会一直留到你作答。

## 设置

- 桌面通知、提示音、任务栏提醒和手机推送集中在「通知」页
- 每种提醒可以分别决定发系统通知还是灵动岛弹出
- 账号与用量、扩展合进「Agent」页，在顶部切换 Agent
- 搜「网络」或「代理」能直接找到代理地址和各 Agent 的设置
- 「接入方式」里点标签只是查看，点「改用官方账号」或「改用 API 中转」才生效

## 改进

- Windows 安装器换了新界面，窗口更小，安装进度看得更清楚
- 有排队消息时，运行条照常显示 agent 正在做的事

## 修复

- Claude 提问时，题目卡会一直保留到你作答
- 手机上打开等了很久的提问，题目不再消失
- 运行中带多张图片发消息，图片会和正文一起送出
- Gemini 运行中发的消息不再显示「未确认送达」，气泡只显示你的原话

## 注意

- 轻量模式已去掉，对话窗口始终可用，设置里不再有「对话窗口功能」开关
- 想让会话在外部终端里打开，到设置「会话」把「打开会话」改成「外部终端」
- Windows 只提供 `-setup.exe` 一个安装包
