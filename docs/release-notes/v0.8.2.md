这一版把「更改」面板做成了 VS Code 源代码管理的样子，能暂存、提交、放弃。agent 在 worktree 里改代码时也看得到。另外加了 Lead 工作流的第一期。

## 「更改」面板

- 按仓库列出改动，可以暂存、取消暂存、放弃，Ctrl+Enter 提交
- 没有暂存任何文件时，按钮是「提交全部」，会提交列表里的全部文件
- 放弃前会确认，写明是哪些文件
- agent 在 worktree 或子仓库里改的文件也会列出来
- 手机页也能暂存、提交和放弃

## Lead 工作流

- 设置里可以把 Lead 工作流装进 Claude Code
- 对话窗底部能看任务的规格和验收进度
- agent 等你拍板时出现关卡卡片，桌面和手机都能答

## 改进

- 灵动岛的会话图标能看出运行中、等你处理和出错
- 提问卡不再 5 分钟后过期
- 新建会话页可以粘贴图片
- 侧栏的工作区可以从列表中移除，文件不受影响

## 修复

- 新建会话发出的第一句话不再重复显示「未确认送达」或卡在「发送中」
- 在会话里跑测试后，对话页不再把它当成外部会话
- 别的会话里不再显示这个会话的 Lead 面板
- 修复了一个安全问题，建议更新
