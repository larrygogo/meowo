这一版的改动面板能对某一行写评论，写好后一键放进输入框发给 agent。审批卡上会标出这次操作碰到哪里，比如工作区外的路径、删除文件、联网。还加了截图按钮，可以在图上框出位置、写好说明再发。另外修了在对话页新建 claude 会话卡在信任页、发图常报「图片附加未完成」的问题。

## 改动面板逐行评论（#90）

- 鼠标移到 diff 的某一行，点「+」写评论。评论显示在那一行下面，文件树上标出条数
- 输入框上方会出一条评论栏，点「插入输入框」，评论按「路径:行号、原代码、意见」排好放进去
- 每个文件后面显示增删行数，顶部显示合计
- 勾上「只看本会话改的」，文件树只留这次会话里改过的文件

## 审批卡标出影响范围（#90）

- 工具那一行下面多一排标签：工作区外的路径、会删除文件、高风险命令、会访问网络
- 确定只改工作区里的文件时，显示绿色的「只改工作区内的文件」
- 附加目录也算工作区。用 `..` 跳出工作区的路径同样会标出来

## 截图并标注（#90）

- 输入框加号旁边多了截图按钮。Windows 上会调出系统的框选截图，macOS 上用系统自带的截图
- 截完弹出标注窗口，拖出的红框自动编号，每个框可以写一句说明
- 点「附上」后，带框的图放进附件，说明按编号接在输入框里
- 已经附上的图片，鼠标移上去左下角有「标注」按钮
- 手机网页版不显示截图按钮

## 回合停在问句上时看得到它在问什么（#90）

- **此前的问题**：agent 最后说的话只存前 200 字。回复一长，结尾的「要我继续吗？」就没了，看板卡片上只看到开头的总结
- **本版改法**：最后一行是问句时，存这句问话。看板卡片显示它，「等待你回复」通知也在标题下带上它

## 新会话信任页在对话页就能处理（#89）

- **此前的问题**：在新目录建 claude 会话，对话页一直显示「会话正在启动…」。其实 claude 停在目录信任页，对话页认不出来，要去终端处理
- **本版改法**：信任页直接在对话页弹卡片，点一下就继续。同时适配了 claude 2.1.304 新的屏幕输出方式
- 会话刚打开时粘的图、打的字，claude 启动完不会再丢

## 发图更稳（#89）

- 等图片附上的时间从 1.5 秒放宽到 10 秒。claude 在 Windows 上读剪贴板图片本机实测要 2.7 秒左右
- 还是没附上时，自动清掉残留的图，改成在正文里附图片路径发出去，claude 自己读图
- 只有清不掉残图时才报错，不会把同一张图附两次

## 旁白和 PowerShell 命令显示正常（#88）

- claude 2.1.304 在工具调用之间说的话，原来被折进「思考过程」，现在和正文显示在一起
- Windows 上的 PowerShell 命令原来显示成一整段参数 JSON，现在和 Bash 一样显示 `$ 命令`。审批框、状态条、后台进度面板都改了
