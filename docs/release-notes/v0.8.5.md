这一版的 PR 功能不再依赖本机 gh，仓库放在 GitLab、Gitee 等平台上也能用。主会话空闲时插话会立即送出，Lead 面板也更好读了。

## 代码托管

- 仓库在 GitLab、Gitea、Bitbucket、Gitee、GitHub 企业版上也能看 PR、合并和评审
- 在设置「代码托管」里登录 GitHub，或添加其他平台的令牌
- 设置里能看到正在用的 git，并修改提交用的名字和邮箱

## Lead

- 验收页只有带证据的条目能展开
- 决定显示成一张张卡片，你的原话单独放在引文框里
- 进度最新的一节在最上面，更早的折起来
- Lead 面板可以点「在侧边面板打开」，放到右侧面板里看

## 改进

- 对话里改过的文件可以点「在「更改」中查看」，直接看 diff
- 面板浏览器可以模拟手机等设备的尺寸和 UA
- 目录已删除的会话能打开看历史，也能在原项目新开会话
- 暗色主题字更轻，中文段尾不再只剩一两个字
- 菜单和卡片改用阴影分层，复制、保存后的提示统一停留 2.5 秒
- API 无响应重试时，运行条会提示
- 子任务面板实时显示时长和 token

## 修复

- 主会话空闲、只剩后台子代理在跑时，插话立即送出
- 后台子代理在跑时，主会话不再显示「工作中」
- 同一项目的其他会话不再显示你的 Lead 任务
- 对话页工具行不再显示参数 JSON，Kimi 的通知显示成发言
- 授权卡答完不再闪一下，切换会话时「更改」页不再闪

## 注意

- Meowo 不再调用本机 gh。原来靠 gh 登录的，请在设置「代码托管」里登录 GitHub
