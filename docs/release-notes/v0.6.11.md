对话窗清爽了：工具调用和思考过程默认收成一行，字号整体放大。对话页的发送、中断、审批和附件，按 Codex、Gemini、Kimi、OpenCode 各自的行为重新适配了一遍。

## 对话窗

- 一组工具调用默认收成一行摘要，点开看明细，改过文件的会显示增删行数
- 思考过程收成一行「思考过程 ›」，点开看全文
- 你发的消息和 agent 的回答字号一样大，按钮和代码块也大了一号
- 界面缩放「小 / 中 / 大」整体大一档，手动选过档位的不受影响
- 侧栏可以拖宽，宽度会记住，每行的「⋯」悬停时才出现

## 各家 agent

- 任务运行中也能发消息，消息排进 agent 自己的队列，跑完接着处理
- Gemini 的工具确认和 OpenCode 的权限请求能在对话页点
- Gemini 额度用完时出卡片说明原因，可以重试或取消
- OpenCode 能切换 Build 和 Plan，Gemini 能轮换审批模式
- Codex、OpenCode 能粘贴图片，只发附件不写正文也能提交
- Codex、Gemini、Kimi、OpenCode 的终端页按 Shift+Enter 换行

## 修复

- OpenCode 在对话页点中断能停下来
- Claude Code、Kimi、Codex 的任务失败或被中断后，卡片回到「等待中」
- Kimi、OpenCode 里拒绝审批后，「待审批」标记会及时撤掉
- Codex 选「Full Auto」启动不再报错退出
- 桌面端重启后，手机页里的图片能自动恢复显示
- macOS 上贴纸不再挡住菜单栏
- 修复了一个安全问题，建议更新

- Kimi 的两个权限档改名为「永不询问」和「按需询问」
