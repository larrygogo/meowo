这一版主要是对话窗减负：工具调用和思考过程默认只占一行灰字，字号、按钮和输入框按更舒展的比例重排，同一屏不再大字小字交错。同时，对话页的发送、中断、审批、切模型和附件，都照着 Codex、Gemini、Kimi、OpenCode 各自的真实行为重新适配了一遍。另外修了手机端在桌面重启后图片打不开、macOS 贴纸挡住菜单栏，以及设置页 agent 卡片的排版。

## 对话页和各家 Agent 配合得更好了（#79）

- **运行中也能发消息**：任务还在跑时发出的消息会进 Agent 自己的排队，跑完接着处理。Codex、Gemini 按 Tab 排队，其余按回车
- **OpenCode 中断生效了**：它要连按两下 Esc 才停，此前只按一下，等于没按
- **Gemini 的审批能在对话页点了**：工具确认框变成审批卡，显示工具和命令，可选允许一次、本会话允许或拒绝
- **Gemini 额度用完不再「发不了消息」**：额度耗尽时 Gemini 会弹框挡住输入框，此前对话页看不到，发出的消息全被吞掉。现在会出一张卡片说明原因，可以选择重试或取消
- **OpenCode 的权限请求**也会在对话页出卡片，确认即允许一次，取消即拒绝
- **切换模式**：OpenCode 可在 Build 和 Plan 之间切换，Gemini 可轮换审批模式，Kimi 打开它自己的权限菜单来选
- **模型清单按会话读取**：用了额外账号或不同项目配置的会话，读到的是它自己的模型清单
- **附件**：Codex、OpenCode 支持直接粘贴图片，附件用 `@路径` 交给 Agent 读取。只发附件不写正文也能正常提交
- **终端页换行**：Codex、Gemini、Kimi、OpenCode 里按 Shift+Enter 换行，不会误提交
- 会话切走后，旧会话没发完的消息不会再替你按回车，也不会清掉新写的草稿

## 会话侧栏（#79）

- **可以拖宽了**：侧栏默认宽一些（208→240px），右缘可拖拽调宽，也能用 ←/→ 键调，宽度会记住
- **「⋯」按钮悬停才出现**：不再每行都占一块，手机端仍常显
- **长标题悬停滚动**：标题太长时，鼠标停上去会滚动显示全文

## 界面缩放整体大一档（#79）

- 「小 / 中 / 大」三档整体上调一档，默认「中」比原来大一号。已经手动选过档位的不受影响
- 外观设置页去掉了预览卡片

## 各家 Agent 的状态更准（#79）

- 任务失败或被手动中断后，卡片会回到「等待中」，不再一直挂着「运行中」（Claude Code、Kimi、Codex）
- 在 Kimi、OpenCode 里拒绝审批后，「待审批」标记会及时撤掉
- Gemini 手动压缩上下文后，不再一直显示「正在压缩」
- **Codex**：新版已去掉 `--full-auto`，选「Full Auto」启动不再报错退出。登录凭据存在系统加密存储时，账号也能正确识别
- **Kimi**：两个权限档的名称改成与 2.2 版含义一致（「永不询问」和「按需询问」）。旧版 Python kimi-cli 不会再被写入它不认识的配置

## 对话窗不那么挤了（#77）

- **工具调用收成一行**：一组工具调用默认只显示一行摘要，比如「搜索文件 · 读取文件 · 运行终端」，点开才看明细。还在跑的看行尾跳动的三个点，失败的标红字「N 个失败」，不再整圈红框
- **改了多少行一眼可见**：动过文件的那组，行尾会显示「-3 +229」这样的增删行数；只读不写的组不显示
- **行首图标按内容换**：改过文件显示笔，否则按用得最多的工具显示放大镜、文件或终端，不再一律是 `>_`
- **思考过程收成一行**：「思考过程 ›」，点开看全文，去掉了原来的圆点、虚线和长思考的预览
- **字号重新拉齐**：你发的消息和 Agent 的回答一样大（13→15px），过程行 11→14px，主次靠灰度区分；会话标题改成常规字重，不再和正文抢眼
- **控件放大一档**：标题栏「对话 / 终端」切换、侧栏搜索框、模型按钮、代码块都大了一号；空着的输入框矮了一截（132→108px）
- 输入框占位符缩短为「发消息给 Agent（Shift+Enter 换行）」
- 看板贴纸、设置页不受影响，贴纸仍保持紧凑

## 桌面重启后，手机端图片自动恢复（#76）

- **此前的问题**：桌面端重启后，开着的手机页里图片全部打不开，变成一个文件名，只能刷新页面
- **本版改法**：图片加载失败时自动重新领取访问凭据，凭据确实换了就把失败的图重试一次
- 用额外账号（profile）登录的 Claude Code，对话里的图片在手机端和桌面端都能正常显示了

## macOS：贴纸不再挡住菜单栏（#75）
