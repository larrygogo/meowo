这一版可以在 Lead 工作流里加一支团队：产品经理先把边界和问题一次问清，设计、开发、审查分头干活，你只在开头答题、结尾验收。

## 团队

- 设置 → 通用 →「Lead 工作流」下打开「团队」，Claude Code 里多出产品经理、设计师、开发、审查员
- 在会话里说「让团队来做：……」，产品经理先出一页纸方案和要你答的问题
- 团队成员不能推送、开 PR、发版或对外发消息，这些留给你批
- 品味清单、不许碰的目录、权限档写在 Meowo 数据目录的 team 文件夹里，升级不会覆盖
- 暂只支持 Claude Code

## 修复

- Lead 任务里子任务中途回报时，不再被误当成已完成而反复提醒

## 注意

- 关掉「Lead 工作流」时，团队会一起关掉
- 已经有同名的团队文件时不会覆盖，设置里会列出是哪个文件
