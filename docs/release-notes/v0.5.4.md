这一版新增 Gemini CLI 和 OpenCode 两个 agent，并支持 API 中转和多账号。

## 新功能

- 新增 Gemini CLI 和 OpenCode，可以在 Meowo 里安装、登录、设代理
- Claude、Codex、Kimi 可以改用 API 中转，填自己的地址和密钥
- 同一个 agent 可以保存多个账号，随时切换
- Kimi 账号显示会员等级

## 改进

- 账号设置页顶部用下拉选 agent，一次只看一个
- 已安装的 agent 排在前面，未安装的置灰
- 安装完成后各处列表立刻刷新
- 默认账号也能改名和删除
- 不支持显示上下文占用的 agent 会标「不支持」

## 修复

- 退出登录只退当前选中的账号，不再误清默认账号
- 新建会话窗口的背景和主面板一致

## 注意

- 设置里的「模型」页改名为「Agent」
