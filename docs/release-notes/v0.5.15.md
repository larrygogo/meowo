这一版在对话窗口旁加了「文件 / 更改」面板，看代码和改动不用离开对话。新增「切换引擎」，一段对话能换个 AI 接着做。Windows 换上了新安装器。

## 文件与更改

- 点对话窗口标题栏的入口，右侧打开面板，对话不会被盖住
- 「更改」列出 git 仓库里改动的文件，点开看着色的 diff
- 「文件」浏览整个项目目录，点文件就能预览
- 面板宽度可以拖动，也能最大化

## 新功能

- 模型下拉里的「切换引擎」把当前会话交给另一个已安装的 AI，在同一目录继续
- 切换前的旧会话保留，侧栏能跳回链上各段
- 标题栏新增「进度」按钮，查看任务清单和子任务，也支持 Claude 新版任务列表
- 一次能粘贴发送多张图片，发完后剪贴板里原来的内容会还原
- 轻量模式：设置里关掉「对话窗口功能」后只保留桌面贴纸，会话在外部终端打开

## 改进

- Windows 新安装器一路下一步即可，「自定义安装」里可以选轻量模式
- 别的会话要审批或提问时不再把窗口切走，改为侧栏亮徽标、任务栏闪烁
- 审批卡在整个等待期间都能作答
- Claude 计划模式问「是否执行」时，看板显示待操作，对话页弹出审批卡

## 修复

- 升级安装时旧文件被占用也能装上
- 等待审批或提问时，终端不再误报卡死
- 后台子任务完成后，状态会变成完成或失败
- Kimi 会话里粘贴的图片，回看历史时也有缩略图
- 上下文占用环满 100% 时数字不再溢出

## 注意

- 会话菜单的「星标置顶」改名为「置顶」
- 电脑上没有 WebView2 时，安装器会用经典界面
