这一版让你一眼看出 agent 在跑还是在等，运行中也能插话或打断，Windows 安装包小了一半多。

## 新功能

- 对话窗标题栏显示运行中、等你输入、未连接或出错，侧栏每个会话有状态点
- 窗口标题带状态记号，在任务栏和 Alt+Tab 里也能看出来
- 本机托管的会话可以在对话窗标题栏结束
- agent 运行中发的消息会排队并显示回执，也可以「打断并发送」或「立即插话」
- 附件按各 agent 自己的方式发送，Claude 和 Kimi 能粘贴图片
- Claude 会话可以选 Fable 模型，能识别 Kimi 的 K3 模型
- Gemini 的 `/model` 菜单显示成可点的卡片

## 改进

- 认错的选择卡会自动收起，每张卡都能「仅收起」
- 认不出终端里的提示时，发送前先提醒你
- 结束会话、接管等确认框换成和应用同风格的小窗
- Windows 安装包从约 11 MB 降到约 4 MB

## 修复

- 重连会话后，输入框里不再多出一个字符
- 进程已退出的会话不再显示运行中
- 对话窗的连接和出错状态能及时更新
- 上一回合的命令不再一直显示在新回合里
