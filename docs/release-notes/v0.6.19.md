发消息改成先上屏再发，切走也不会取消。会话需要你时能推送到手机。手机远程页看对话、处理审批都顺了很多。

## 发消息

- 点发送后消息马上出现在对话里，标着「发送中」，可以接着打下一条
- 发出后切回会话列表不再取消发送，终端没起来会在后台拉起再发
- 发送失败的消息留在原处，可以「重发」或「放回输入框」

## 手机远程页

- 在「设置 → 网络」填上 Bark 地址，审批、出错、回合结束时会推送到手机
- 会话列表优先显示，进对话后可以返回列表
- 审批卡的「展开全部 / 复制命令」固定在底部，不再被挡住
- 助手回复里的表格放不下时可以左右滑

## 对话窗与侧栏

- 会话列表默认按创建时间排，在跑的会话不再一直换位置
- 当前会话所在的分组也能折叠
- 切换引擎改成复制到一个新会话，原会话不结束

## 修复

- 对话内搜索能输入中文
- 发出后切走再回来，消息不再误标「未确认送达」
- 「回到最新」上的数字只数消息
- OpenCode 会话的对话页能看到完整对话
- 被停掉的后台任务不再一直显示运行中
- Claude Code 新版派生的后台会话不再抢走 Meowo 托管的终端
- macOS 贴纸跟着主题切换外观，底栏不再溢出

## 注意

- 去掉了附加目录功能和右键菜单里的「新建会话」
- Bark 推送的内容会经过 Bark 的服务器
